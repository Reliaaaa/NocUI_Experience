# notchX reference

The notch motion and layout work in this repository refers to [notchX / DynamicBar](https://github.com/rahozosman/notchX), revision `96b865c`. The source repository's README states “Copyright © 2026 Rahoz Osman. All rights reserved.” The user stated in the project chat that they have permission to use and adapt its source; retain the permission record separately with the project.

The current WinUI implementation adapts the idea of letting the shape lead incoming content and letting content exit sooner. It uses the existing NocUI animation and settings architecture; it is not a port of the Flutter spring engine. Runtime behavior and performance must be verified on Windows.
