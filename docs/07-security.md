# Review keamanan NotchUI

Tanggal pembaruan: 2026-11-05. Metode: review manual statis terdahulu terhadap source `src/NotchUI`, dilanjutkan inspeksi perubahan lokal bounded storage, schema/error preservation, UI lifecycle serta supporting interop dan bootstrap. Source self-check diperiksa; upaya menjalankannya pada lingkungan ini gagal karena `dotnet` tidak tersedia. Tidak ada perubahan kode keamanan yang diterapkan oleh review ini. Review ini bukan hasil eksekusi Codex Security scanner, audit dependensi daring, atau pengujian Windows.

## Hasil dan batas bukti

Tidak ditemukan vulnerability Critical/High yang dapat dibuktikan dari source yang tersedia. Aplikasi adalah utility lokal: tidak ada listener jaringan, server, WebView, eksekusi shell, input path pengguna, autentikasi, token, atau penyimpanan metadata media pada source yang diperiksa. Ini tidak berarti aplikasi sudah memperoleh persetujuan rilis keamanan. Review lanjutan pada tanggal yang sama mencakup bootstrap `App`, coordinator, UI XAML, project aplikasi, dan manifest MSIX yang baru ditambahkan.

Batas kepercayaan utama: JSON preferensi per pengguna masuk ke codec; metadata media berasal dari aplikasi lain melalui GSMTC; pesan Win32 masuk melalui HWND; callback native memanggil managed code. Proses desktop harus berjalan dengan hak pengguna biasa. MSIX dan LocalSettings bukan batas isolasi terhadap proses lain dengan akun Windows yang sama; data yang disimpan memang hanya preferensi nonrahasia.

## Temuan dan tindak lanjut

| ID | Severity | Lokasi | Bukti, dampak, mitigasi dan status |
| --- | --- | --- | --- |
| SEC-01 | Low — hardening availability | `Interop/TrayIconHost.cs`, `WndProc`/`ShowMenu`; `Interop/OverlayWindowHost.cs`, `WndProc` | Action Settings/Exit dan event `SystemStateChanged`/`DisplayChanged` dipanggil dari callback native tanpa penanganan exception pada batas callback. Bootstrap menghubungkan Settings ke pembuatan/aktivasi `MainWindow`; exception pada jalur ini dapat keluar dari callback native dan menghentikan proses. Startup catch tidak melindungi callback tray yang terjadi kemudian. Tangani kegagalan recoverable pada subscriber/batas callback dan uji kegagalan membuka Settings; jangan membiarkan exception melintasi batas unmanaged. Status: terbuka, dampak crash belum direproduksi di Windows, bukan eskalasi privilege. |
| SEC-02 | Low — hardening input | `Services/MediaService.cs`, `Refresh` | Judul/artis dari sesi aplikasi lain diteruskan apa adanya. String besar atau event metadata berulang dapat menambah alokasi/layout UI; tidak ada sink HTML, XAML parsing, command, atau file yang terbukti, sehingga injeksi kode tidak ditemukan. UI memakai `TextBlock.Text` dengan trimming, tetapi ini tidak membatasi alokasi string atau jumlah request async. Pertimbangkan batas panjang dan coalescing refresh jika stress test memperlihatkan beban. Status: terbuka; dampak UI belum diuji di Windows. |
| SEC-03 | Verification gap — release gate | `Package.appxmanifest`, manifest proses hasil build | Manifest source hanya meminta `runFullTrust`, tanpa internet, library luas, administrator atau UIAccess. Gunakan `asInvoker` pada manifest executable final. Uji sebagai pengguna standar serta penolakan akses media (service sudah mengubah kegagalan menjadi state Error). Status: source capability ditinjau; paket final belum diuji. |
| SEC-04 | Verification gap — release gate | `NotchUI.csproj`; `02-architecture.md` | Source mengunci satu dependency langsung `Microsoft.WindowsAppSDK` ke `1.6.250205002`, target .NET 8, tanpa toolkit MVVM aktual. Verifikasi dukungan versi, advisori langsung/transitif (`dotnet list package --vulnerable --include-transitive`) dan lock hasil restore pada mesin Windows; audit MSIX final. Status: konfigurasi source ditinjau, restore/advisori belum terverifikasi. |
| SEC-05 | Verification gap — lifecycle | `App.xaml.cs`, `OverlayWindow.xaml.cs`, `NotchCoordinator.cs` | `App` mempertahankan tray/overlay/coordinator; overlay mempertahankan host sehingga delegate subclass tetap rooted. Kekhawatiran source tentang storyboard yang tidak dihentikan sudah ditangani. Timing `Closed` terhadap kehancuran HWND dan keberhasilan `RemoveWindowSubclass` masih perlu dibuktikan di Windows. Temuan Low di atas adalah peluang hardening dengan dampak lokal yang terbatas, bukan vulnerability privilege/confidentiality yang terkonfirmasi. Pesan tray dapat dipalsukan oleh proses pengguna yang sama; Settings/Exit hanya menjalankan aksi lokal dengan hak yang sudah dimiliki. Jangan memperlakukan nomor pesan sebagai bukti identitas atau menambahkan aksi sensitif berbasis pesan tersebut.

Review integrasi: `OverlayWindow` menempatkan judul/artis langsung ke `TextBlock.Text` dengan `TextTrimming`, bukan parser markup; SEC-02 terbatas pada alokasi/event burst, bukan injeksi. Warna UI berasal dari snapshot Normalize sehingga substring/konversi tidak memproses string JSON mentah. Coordinator kini menerapkan debounce penyimpanan 400 ms dengan timer UI nonrepeating: perubahan diterapkan ke sesi segera, lalu snapshot terakhir disimpan. `Dispose` melakukan flush sinkron, menghentikan timer dan melepas handler Tick sebelum disposal service. Save gagal mempertahankan dirty state untuk upaya berikutnya; tidak ada retry berkala otomatis. Perilaku timer/Exit belum diuji pada Windows dan penghentian proses mendadak tetap dapat kehilangan perubahan yang belum tersimpan. Bootstrap memakai `AppInstance.FindOrRegisterForKey` dan redirect activation untuk single-instance; ini kontrol konsistensi, bukan batas akun/privilege. `Activate()` overlay awal berpotensi mengambil fokus dan merupakan isu UX. Startup mempunyai catch, pesan error dan `Shutdown`; cleanup parsial masih perlu diuji. Log lokal `startup-error.log` berisi `exception.ToString()` sehingga dapat memuat path profil dan detail lingkungan; tidak ada metadata media yang sengaja dicatat, tetapi log ini tidak boleh dianggap selalu bebas informasi pribadi saat dibagikan.

## Kontrol yang sudah terlihat pada source

- `SettingsCodec` membatasi input 4096 karakter, memakai `System.Text.Json` bertipe tetap tanpa polymorphic type loading, menolak versi/tipe salah, dan menormalisasi ukuran, nilai nonfinite, radius serta warna `#RRGGBB`. Parser JSON memiliki batas kedalaman default. Tidak ada path traversal atau deserialisasi objek arbitrer.
- Mode unpackaged membaca melalui `StreamReader` dengan deteksi BOM dan buffer maksimal 4097 karakter (4096 ditambah satu pendeteksi oversize), termasuk ketika reader memberi short read. Pembatasan ini berlaku pada karakter hasil decode, bukan ukuran byte file; buffer internal reader tetap terbatas. Tidak ada `ReadAllText` pada jalur load tersebut.
- `SettingsService` menyimpan preferensi nonrahasia, menangkap kegagalan storage, serta menjaga versi lebih baru dari overwrite setelah Load. Kedua mode memblokir Save setelah oversize atau kegagalan baca; packaged kini juga mempertahankan nilai LocalSettings yang bukan string melalui `CanInspectStoredValue`. Guard packaged diperiksa setelah nilai LocalSettings dimaterialisasi, sehingga bukan batas alokasi pada API storage. Data tidak ditemukan mengizinkan Save, sedangkan JSON rusak dalam batas ukuran memakai backup/default dan boleh diganti. Load valid berikutnya membuka blokir. Packaged memakai backup LocalSettings; unpackaged menulis file `.tmp` lalu move/overwrite dan tidak memiliki backup. Pesan error settings tidak memuat payload atau profil. Lock hanya berlaku pada satu instance service dan bukan proteksi terhadap proses lain pada akun sama. Guard packaged ini diverifikasi secara statis; integrasi Windows belum dijalankan.
- Geometri overlay menolak nonfinite dan menjepit ukuran ke monitor. `SetWindowRgn` menyerahkan region kepada Windows saat sukses dan memanggil `DeleteObject` saat gagal. Penggantian region merupakan kepemilikan sistem. Region tidak dibebaskan lagi setelah transfer sukses.
- Menu tray memakai `finally` untuk `DestroyMenu`. Ikon dari `LoadIcon(NULL, IDI_APPLICATION)` adalah shared system icon dan tidak memerlukan `DestroyIcon`. Constructor gagal mencoba melepas subclass; Dispose tray idempoten.
- Battery hanya membaca status daya; clock hanya waktu lokal. Media memakai API sesi lokal, memeriksa kemampuan kontrol dan busy state, melepas event, serta memakai generation/version untuk mengabaikan hasil async lama. Stop media menghapus metadata dari state.
- P/Invoke memakai nama DLL sistem tetap, bukan input pengguna; tidak ada pointer arithmetic atau dereference pointer dari pesan eksternal. `lParam` hanya dibaca sebagai koordinat/angka pesan. Pembatasan pencarian DLL ke System32 dapat dipertimbangkan sebagai hardening eksplisit; tidak ada jalur DLL hijack yang dibuktikan di sini.

## Verifikasi wajib pada Windows sebelum rilis

1. Build/restore paket final sebagai pengguna standar; inspeksi manifest, daftar paket transitif, signature dan sertifikat MSIX. Pastikan installer tidak meminta elevasi yang tidak diperlukan.
2. Uji startup gagal, penutupan dashboard, Exit dari tray, Explorer restart, pengulangan buka/tutup Settings, dan sleep/resume. Pantau handle USER/GDI agar stabil serta pastikan tidak ada callback sesudah disposal.
3. Uji sudut transparan lintas proses dan geometri selama animasi; notch tidak boleh menutup input di luar area visual. Topmost tidak memberi hak untuk meniru prompt keamanan atau muncul di secure desktop.
4. Uji metadata panjang, Unicode/bidi, sesi media berganti selama await, event burst, akses media ditolak, dan toggle off selama request. Teks diperlakukan sebagai data; metadata tidak masuk log/storage.
5. Jalankan self-check codec/storage; source mencakup short reads, batas 4096/4097, BOM UTF-8/UTF-16, future schema dan preservation setelah gagal baca, serta reload valid. Uji juga deep nesting, kegagalan write/move, pemulihan backup packaged, preservation oversized/non-string LocalSettings, debounce 400 ms serta flush ketika Exit sebelum timer berakhir pada Windows. Self-check belum dijalankan dalam pembaruan ini karena `dotnet` tidak tersedia dan tidak membuktikan integrasi LocalSettings atau API native.

Status akhir review: seluruh source aplikasi yang tersedia, termasuk bootstrap/UI, coordinator dan konfigurasi paket, mendapat review statis. Tidak ada patch High/Critical yang diperlukan. Supply chain hasil restore, manifest executable/MSIX final dan perilaku native Windows masih memerlukan verifikasi. Tidak ada secret yang ditemukan dalam source/dokumen implementasi yang diperiksa; git history, file akun di luar scope, binary, dan arsip referensi tidak diaudit sebagai secret scan.
